The record is nowhere near complete, and some of it is surely wrong. Every total on the site is a sum of what the database holds rather than of what happened; the coverage note says what is on file and where it stops. If you catch an error, every page carries a link to report it. If you have a season the database is missing, get in touch. The data and the code that build this site are public on GitHub.
